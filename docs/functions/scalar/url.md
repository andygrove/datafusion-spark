## `try_url_decode`

Same as `url_decode`, except that a value which cannot be decoded returns NULL for that row instead of an error. DataFusion has no built-in `try_url_decode`.

```sql
try_url_decode(str)
```

### Arguments

- **str**: String expression to decode. NULL, or a value that cannot be decoded, returns NULL.

### Example

```sql
> SELECT try_url_decode('Spark+SQL%21');
Spark SQL!
> SELECT try_url_decode('https%3%2F%2Fspark.apache.org');
NULL
```

## `url_decode`

Decodes a string in `application/x-www-form-urlencoded` format, the inverse of `url_encode`. DataFusion has no built-in `url_decode`. `+` becomes a space and each `%XX` escape becomes the byte it encodes, and the bytes are read as UTF-8. A `%` that is not followed by two hex digits, or bytes that are not valid UTF-8, are an error; use `try_url_decode` to get NULL instead. Returns NULL if the input is NULL.

```sql
url_decode(str)
```

### Arguments

- **str**: String expression to decode. NULL returns NULL.

### Example

```sql
> SELECT url_decode('https%3A%2F%2Fspark.apache.org');
https://spark.apache.org
> SELECT url_decode('Spark+SQL%21');
Spark SQL!
> SELECT url_decode('%E4%BD%A0%E5%A5%BD');
你好
```

## `url_encode`

Encodes a string in `application/x-www-form-urlencoded` format, like Java's `URLEncoder` with UTF-8, which Spark uses. DataFusion has no built-in `url_encode`. Letters, digits and `.`, `-`, `*` and `_` are kept, a space becomes `+`, and every other byte of the UTF-8 encoding becomes `%XX` with uppercase hex digits. Returns NULL if the input is NULL.

```sql
url_encode(str)
```

### Arguments

- **str**: String expression to encode. NULL returns NULL.

### Example

```sql
> SELECT url_encode('https://spark.apache.org');
https%3A%2F%2Fspark.apache.org
> SELECT url_encode('Spark SQL');
Spark+SQL
> SELECT url_encode('你好');
%E4%BD%A0%E5%A5%BD
```
